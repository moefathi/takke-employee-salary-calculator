# TAKKE Employee Salary Calculator (TESC)

## Project Overview
The TAKKE Employee Salary Calculator (TESC) is an application developed using Adalo to support employee salary management and salary calculations. The system provides separate functionality for HR users and employees.

## Application Features
- Separate access for HR users and employees.
- Employee information management.
- Salary-related calculations and information.
- Database collections and relationships to organize application data.
